# Ozark Gutter Guard Co.

Direct-to-consumer 316 surgical stainless steel micro-mesh gutter protection and exterior drainage solutions across Northwest Arkansas (Bentonville, Bella Vista, Rogers, Fayetteville, Springdale, and all NWA ZIP codes).

## Tech Stack
* **Framework**: Next.js 15 (App Router)
* **Language**: TypeScript
* **Styling**: Tailwind CSS
* **Icons**: Lucide React
* **Deployment**: Vercel Ready

## Key Features
* **Trojan Horse Customer Acquisition Engine**: $149 Diagnostic Cleanout & 21-Point Roofline Audit (100% credited toward permanent guards).
* **Hyper-Local NWA Geo-Silos**: Dedicated pages for all 20+ NWA postal codes and key neighborhoods.
* **Instant Satellite Sizing Estimator**: 15-minute digital quote generator.
* **Full Local SEO & Schema Graph**: E-E-A-T entity stacking, Wikipedia linking, dynamic XML sitemap, and Google Business Profile optimization.

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
